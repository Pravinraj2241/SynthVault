Product workflow

Five steps from raw file to verified synthetic data

Each step runs inside your own project workspace, and every result stays available for review before you move on.

  1. 01

    Step 01: Upload Dataset

    Send a CSV file into a project workspace; SynthVault validates and stores the original securely.

  2. 02

    Step 02: Detect Schema & PII

    Every column is typed and scanned for personal data such as emails, phone numbers, Aadhaar, PAN and cards.

  3. 03

    Step 03: Analyze Privacy Risk

    A scored privacy report grades the dataset from LOW to CRITICAL and explains which columns drive the risk.

  4. 04

    Step 04: Generate Synthetic Data

    Choose a row count and generate a replacement dataset whose sensitive fields are fabricated, never copied.

  5. 05

    Step 05: Verify Similarity

    Compare per-column and overall statistics to confirm the synthetic data still represents the original.

Platform value

Privacy, generation and proof in one place

Privacy Analysis

Automatic schema detection and PII classification run on upload, then a weighted privacy score turns those findings into one clear risk level for the dataset.

Synthetic Generation

Generate any row count you need. Sensitive identifiers are synthesised, numeric and date ranges stay inside the original bounds, and category values are sampled from the real distribution.

Statistical Verification

Verify per-column and overall similarity between the original and synthetic data so you can prove the output is representative before it leaves your team.

Security

Controls implemented in the platform today

Only capabilities that already exist in the platform are listed here. Anything still on the roadmap is deliberately left out rather than advertised early.

  • JWT authentication

    Sessions are issued on login and required by every protected endpoint.

  • Role-based access control

    USER and ADMIN roles separate everyday work from administration endpoints.

  • API-key support

    Non-interactive integrations can authenticate with a managed API key.

  • Rate limiting

    Requests are throttled so a single caller cannot exhaust the platform.

  • Audit logging

    Security-relevant actions are recorded for later review.

Technology

Built on a mainstream, auditable stack

  • React 18
  • Spring Boot 3
  • Java 21
  • MySQL
  • Spring Data JPA
  • Spring Security
  • JWT
  • REST API
  • Docker
  • Render deployment

Frontend

A React 18 single-page app built with Vite and styled with Tailwind CSS. It talks to the API with Axios and keeps routing, menus and drag-and-drop on native browser APIs rather than extra UI or state libraries.

Backend

A Spring Boot 3 REST API on Java 21, secured with Spring Security and JWT, persisting through Spring Data JPA and packaged with Docker for deployment.
